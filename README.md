# UIDAI Accessibility Audit

## Project Overview
This project evaluates the accessibility of the official UIDAI website (https://uidai.gov.in/) using automated and manual testing methods.

The purpose is to identify accessibility barriers and recommend improvements based on Web Content Accessibility Guidelines (WCAG).

## Objectives
- Perform an accessibility audit using Google Lighthouse.
- Conduct keyboard-only navigation testing.
- Identify and document accessibility issues.
- Recommend improvements to make the website more accessible.
- Establish a basic monorepo project structure.

## Repository Structure

- `client/` – Frontend application.
- `server/` – Backend application.
- `docs/` – Audit reports, screenshots and documentation.
- `tests/` – Testing resources and test cases.

## Tools Used
- Google Lighthouse
- Chrome DevTools
- GitHub
- WCAG Guidelines

## Project Status
Accessibility testing and repository setup are in progress.
